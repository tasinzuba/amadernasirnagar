# আমাদের নাসিরনগর

ব্রাহ্মণবাড়িয়া জেলার নাসিরনগর উপজেলার ১৩টি ইউনিয়ন ও ১২৮টি গ্রামের পরিচয়, দর্শনীয় স্থান, বিশিষ্ট ব্যক্তি, খবর, উৎসব, যাতায়াত ও জরুরি তথ্যের ওয়েবসাইট।

Next.js 16 (App Router) + Tailwind CSS 4 + Leaflet + Motion দিয়ে তৈরি। কনটেন্ট থাকে Neon Postgres ডেটাবেসে (`DATABASE_URL` দিলে); না দিলে `content/` ফোল্ডারের JSON ফাইল থেকেই সাইট চলে। দুই ক্ষেত্রেই তথ্য zod দিয়ে যাচাই হয়, আর অ্যাডমিন প্যানেল থেকেই সব সম্পাদনা করা যায়।

## ডিজাইন

ডিজাইন BRIX Templates-এর Webflow টেমপ্লেট "Agencypro X" (agencyxtemplate.webflow.io/homes/home-v1)-এর ধাঁচে করা (২০২৬-১০-০৮)। টেমপ্লেটের ছবি, ইলাস্ট্রেশন বা কোড নেওয়া হয়নি; শুধু রং, আকার ও লেআউটের ধরন অনুসরণ করা হয়েছে, কনটেন্ট নাসিরনগরের।

- **রং:** গাঢ় নেভি শিরোনাম `#14142b` (brand-900), নীলচে ধূসর লেখা `#6e7191` (ink-500), কোরাল অ্যাকসেন্ট `#ff3951` (accent-500), হালকা ল্যাভেন্ডার সেকশন `#f5f7fc` (brand-50)। সহায়ক রং iris `#6a35ff`, azure `#3d7fff`, sky `#00a0ff`, sunny `#ffc632`। সব টোকেন `src/app/globals.css`-এর `@theme` ব্লকে।
- **অক্ষর:** ইংরেজি অক্ষর Plus Jakarta Sans, বাংলা শিরোনাম Anek Bangla, বাংলা পড়ার লেখা Hind Siliguri। বাংলায় letter-spacing দেওয়া হয়নি, কারণ তাতে মাত্রা ভেঙে যায়।
- **উপাদান:** কোরাল পিল বোতাম (কোরাল ছায়াসহ), সাদা পিল দ্বিতীয় বোতাম, ৩২–৪৪px গোল কোণার সাদা কার্ড, পিল আকৃতির ইনপুট, সামনে ছোট দাগসহ কোরাল উপশিরোনাম (`.section-eyebrow`), টিকচিহ্নের তালিকা (`Checklist`), দুই স্তরের রঙিন আইকন-টাইল (`IconTile`)।
- **হোমপেজ:** হিরো (পুরো চওড়া হাওরের ছবি পটভূমিতে, বাঁ দিকে নেভি ছায়ার ওপর সাদা শিরোনাম ও দুটি পিল বোতাম) → ছবির নিচের কিনারায় বসানো এক নজরে প্যানেল → "এক জায়গায় সব" কার্ড-স্লাইডার → মানচিত্র ও যাতায়াত → উপজেলার ইতিহাস-কার্ড → দর্শনীয় স্থানের স্লাইড → রঙিন মাথার গ্রাম-কার্ড → বিশিষ্ট ব্যক্তির স্লাইড → খবর ও উৎসব → তথ্য দেওয়ার ফর্ম → ফুটার (খোঁজার বাক্সসহ)।
- **ভেতরের পেজের শিরোনাম-ব্যান্ড** (`PageHeader`, `src/components/section.tsx`): গাঢ় রঙের পটভূমিতে বড় ঘরের হালকা গ্রিড, বাঁয়ে ও ডানে-ওপরে বড় বৃত্ত, ওপরে ব্রেডক্রাম্ব আর সরু রেখা, উজ্জ্বল রঙের ছোট উপশিরোনাম, বড় সাদা শিরোনাম, ডানে উজ্জ্বল কিনারার ফ্রেম (`HeaderFrame`), যার ওপরে-বাঁয়ে ছোট ট্যাগ। ফ্রেমে কভার ছবি থাকলে ছবি, না থাকলে বৃত্তের মাঝে আইকন আর পেজের মূল সংখ্যা। মোবাইলে ফ্রেম লুকানো থাকে, কভার ছবি তখন লেখার ওপরে আসে। নকশা সব পেজে এক, রং আলাদা: গ্রাম নীল, ইউনিয়ন বেগুনি, দর্শনীয় স্থান সবুজাভ নীল, গুণী মানুষ ওয়াইন, খবর ধূসর-নীল ও হলুদ, উৎসব প্লাম, যাতায়াত সবুজ, জরুরি লাল, মানচিত্র ইন্ডিগো, উপজেলা বাদামি-সোনালি, তথ্য দিন কমলা, পরিচিতি সায়ান। রং বদলাতে `src/components/page-theme.ts`।
- **লেখার ধরন:** সাইটের সব লেখা কথ্য, সহজ বাংলায় ("আপনার গ্রামের কথা লিখে পাঠান", "এখনো লেখা হয়নি")। ওয়েবপেজ বোঝাতে সবখানে "পেজ" লেখা হয়, "পাতা" নয়। নতুন লেখা যোগ করার সময় এই ধরন রাখুন।
- **স্লাইডার:** `src/components/carousel.tsx` (`ScrollRow` আড়াআড়ি সারি, `Slides` একবারে একটি)।
- **গ্রামের অবস্থা:** যে গ্রামের পরিচিতি লেখা হয়েছে তার পাশে কোরাল বিন্দু, না হলে ফাঁপা বৃত্ত (`Lamp`, `status-badge.tsx`)।
- **ছবি:** আসল ছবি থাকলে কার্ডে দেখায়; না থাকলে হালকা রঙের প্যানেলে আইকন। ছবি যোগ করলে আপনা-আপনি বদলে যাবে।

হিরোর ছবি: `public/images/hero.jpg` (প্রস্থ ১৬০০–২০০০px), পুরো হিরো জুড়ে পটভূমি হিসেবে বসে। বাঁ দিকটা একটু অন্ধকার হলে লেখা ভালো পড়া যায়।

## অ্যাডমিন প্যানেল (/admin)

সব কনটেন্ট ব্রাউজার থেকে এডিট করার জায়গা। `npm run dev` চালিয়ে http://localhost:3000/admin খুলুন।

- **পাসওয়ার্ড:** প্রজেক্টের `.env.local` ফাইলে `ADMIN_PASSWORD=...` (ফাইলটি git-এ যায় না)। বদলালে সবাই লগআউট হয়ে যায়।
- **কী কী এডিট করা যায়:** গ্রাম (সব ফিল্ড, ছবি, মানচিত্রে ক্লিক করে অবস্থান), ইউনিয়ন, দর্শনীয় স্থান, বিশিষ্ট ব্যক্তি, খবর, উৎসব, জরুরি নম্বর। "জমা পড়া তথ্য" পেজে সাইটের "তথ্য দিন" ফর্মের জমাগুলো দেখা যায়।
- **প্রিভিউ:** এডিট পেজের ডানে সাইটের আসল পেজ দেখায়; সেভ করলেই রিলোড হয়। "সাইটে দেখুন" বোতামে নতুন ট্যাবে খোলে।
- **ছবি:** ফর্মে ছবি বাছাই করলে ব্রাউজারেই ছোট হয়ে যায়, তারপর সার্ভারে ১৬০০px চওড়া JPG বানিয়ে ডেটাবেসে রাখা হয় (সাইটে `/media/...` ঠিকানায় দেখায়)। ডেটাবেস না থাকলে `public/images/...` ফোল্ডারে জমা হয় (নিচের "ছবি যোগ করা" অংশের নিয়মেই)। ফোল্ডারে আগে থেকে থাকা ছবিও ফর্মে দেখায়। ডেটাবেস-মোডে সেগুলো নতুন ছবি দিয়ে বদলানো বা গ্যালারি থেকে সরানো যায়, তবে ফোল্ডারের কভার ছবি একেবারে মোছা যায় না।
- **গ্রাম একটা একটা করে পূর্ণ করা:** ড্যাশবোর্ডের "পরবর্তী কাজ" তালিকা বা গ্রাম পেজের "তথ্য নেই" ফিল্টার থেকে গ্রাম খুলুন, তথ্য দিন, অবস্থা "আংশিক" বা "পূর্ণাঙ্গ" করুন, সেভ করুন।
- **প্রকাশ করা:** ডেটাবেস থাকলে সেভ করামাত্র লাইভ সাইটে বদল দেখায়, git push বা নতুন ডিপ্লয় লাগে না। লোকাল `npm run dev` আর লাইভ সাইট একই ডেটাবেস ব্যবহার করলে যেকোনো জায়গা থেকে এডিট করা যায়। ডেটাবেস না থাকলে সেভ করলে `content/` ফোল্ডারের JSON ফাইল বদলায়; তখন লাইভে নিতে git commit ও push করতে হয়, আর Vercel-এ (read-only) এডিট করা যায় না।
- **নিরাপত্তা:** `src/proxy.ts` প্রতিটি /admin রিকোয়েস্টে কুকি যাচাই করে; প্রতিটি সার্ভার অ্যাকশনও আলাদাভাবে যাচাই করে।
- **লোকালে নতুন পেজ এরর দিলে:** `npm run dev` চলাকালে অ্যাডমিন থেকে নতুন গ্রাম, স্থান বা শিক্ষা প্রতিষ্ঠান যোগ করলে তার নিজস্ব পেজ কখনো এরর (৫০০) দিতে পারে, কারণ ডেভ সার্ভার পেজের তালিকা আগের মতো মনে রাখে। dev সার্ভার বন্ধ করে আবার চালু করলেই ঠিক হয়। লাইভ সাইটে (Vercel) এ সমস্যা হয় না, নতুন পেজ সঙ্গে সঙ্গে তৈরি হয়।

## ডেটাবেস (Neon Postgres)

`.env.local`-এ `DATABASE_URL` থাকলে সাইট সব তথ্য ডেটাবেস থেকে পড়ে, আর অ্যাডমিন প্যানেল ও "তথ্য দিন" ফর্ম ডেটাবেসেই লেখে। ডেটাবেসে তিনটা টেবিল:

- `content_docs`: `content/` ফোল্ডারের প্রতিটা ফাইল এক সারিতে (`unions`, `places`, `people`, `news`, `events`, `emergency`, `schools`), আর প্রতিটা গ্রাম `village:<slug>` নামে
- `submissions`: "তথ্য দিন" ফর্মে জমা পড়া তথ্য
- `media`: অ্যাডমিন থেকে আপলোড করা ছবি (`src/app/media/[...path]/route.ts` দেখায়)

নতুন ডেটাবেসে প্রথমবার:

```bash
# .env.local-এ: DATABASE_URL=postgresql://...  (Neon ড্যাশবোর্ড → Connect → pooled connection string)
npm run db:setup     # টেবিল বানায়
npm run db:push      # content/ ফোল্ডারের তথ্য আর submissions/ ফোল্ডারের জমা ডেটাবেসে তোলে
```

অন্যান্য কমান্ড:

```bash
npm run db:status                      # ডেটাবেসে কী আছে, আর content/ ফোল্ডারের সঙ্গে কোথায় অমিল
npm run db:pull                        # ডেটাবেসের তথ্য content/ ফোল্ডারে নামায় (ব্যাকআপ বা git-এ রাখার জন্য)
npm run db:push -- village:haripur     # শুধু নির্দিষ্ট তথ্য তোলে (একাধিক নাম দেওয়া যায়)
npm run db:push -- --prune             # ফোল্ডারে নেই এমন গ্রাম ডেটাবেস থেকে মোছে
```

- `content/.db-sync.json` মনে রাখে শেষবার কোন তথ্য মিলেছিল। তাই `db:push` অ্যাডমিন থেকে করা নতুন বদলের ওপর লেখে না, আর `db:pull` ফোল্ডারের না-তোলা বদল মোছে না। দুই দিকেই বদল থাকলে "অমিল" দেখায়; কোনটা রাখবেন ঠিক করে `--force` দিয়ে চালান (`push --force`: ফোল্ডারেরটা থাকে, `pull --force`: ডেটাবেসেরটা)।
- সাইট ডেটাবেসের তথ্য এক ঘণ্টা পর্যন্ত ক্যাশে রাখে। অ্যাডমিন থেকে সেভ করলে সঙ্গে সঙ্গে নতুন হয়। `db:push` বা সরাসরি SQL দিয়ে বদলালে অ্যাডমিন ড্যাশবোর্ডের "সাইট রিফ্রেশ" বোতাম চাপুন।
- `DATABASE_URL` না দিলে সব আগের মতো `content/` ফোল্ডার থেকে চলে।

## হাতে JSON এডিট করতে চাইলে

অ্যাডমিন প্যানেলই সহজ পথ, তবে চাইলে `content/villages/<slug>.json` সরাসরি এডিট করা যায়:

```json
{
  "slug": "aliara",
  "name": "আলিয়ারা",
  "nameEn": "Aliara",
  "union": "haripur",
  "status": "partial",
  "tagline": "এক লাইনে গ্রামের পরিচয়",
  "description": "গ্রামের পরিচয় কয়েক লাইনে...",
  "attractions": ["place-slug"],
  "institutions": [{ "name": "আলিয়ারা সরকারি প্রাথমিক বিদ্যালয়", "type": "প্রাথমিক বিদ্যালয়" }],
  "markets": [{ "name": "আলিয়ারা বাজার", "days": "রবি ও বুধবার" }],
  "lat": 24.11,
  "lng": 91.25
}
```

ফাইলের নাম ও `slug` এক হতে হবে। ভুল থাকলে পেজ খোলার সময় বা `npm run build`-এ বাংলায় এরর দেখাবে। সব ফিল্ডের তালিকা `src/lib/schemas.ts` ফাইলে।

ডেটাবেস ব্যবহার করলে আগে `npm run db:pull` চালিয়ে সর্বশেষ তথ্য নিন, ফাইল এডিট করুন, তারপর `npm run db:push`, শেষে অ্যাডমিনের "সাইট রিফ্রেশ" চাপুন।

## সাইটের সব লেখা এক ফাইলে (site-content/site-content.json)

সাইটের সব পেজের লেখা (হোমপেজ, ভেতরের পেজ, মেনু, ফুটার, ফর্ম) আর `content/` ফোল্ডারের তথ্য একসঙ্গে একটা JSON ফাইলে পাওয়া যায়, পেজ ধরে ধরে সাজানো। ফাইলটা নিজে বদলাতে পারেন, বা অন্য কাউকে দিয়ে লিখিয়ে নিতে পারেন। তারপর এক কমান্ডে বদলগুলো সাইটে বসে।

```bash
npm run content:export          # কোড আর তথ্য থেকে ফাইলটা নতুন করে বানায় (আগের site-content.json মুছে যায়)
npm run content:apply -- --dry  # কী কী বদলাবে শুধু দেখায়
npm run content:apply           # বদলগুলো কোড আর content/ ফাইলে বসায়, তারপর ফাইলটা নতুন করে বানায়
```

- শুধু ডান পাশের লেখা বদলান। বাঁ পাশের নাম (যেমন `121 · span`) আর `{ }` বন্ধনীর ভেতরের অংশ বদলাবেন না। বন্ধনীর জায়গায় সাইট নিজে সংখ্যা বা নাম বসায়।
- কোনো লাইনে সমস্যা থাকলে (যেমন `{ }` মুছে গেছে) apply কিছুই বসায় না, কোন লাইনে সমস্যা তা দেখায়।
- লেখা বদলে apply না করে `content:export` চালাবেন না। তাহলে বদলগুলো মুছে যাবে।
- `site-content/.base.json` বদলাবেন না। ওটার সঙ্গে মিলিয়েই বোঝা যায় কোন লেখা বদলেছে।
- কাজটা করে `scripts/site-content.mjs`। কোডের লেখা খোঁজে TypeScript পার্সার দিয়ে, তাই নতুন পেজ বা নতুন লেখা যোগ হলে আবার export করলেই ফাইলে চলে আসে।
- `DATABASE_URL` থাকলে export আর apply আগে ডেটাবেস থেকে সর্বশেষ তথ্য নেয় (অ্যাডমিনের বদলও তাই ধরা পড়ে), আর apply শেষে বদলানো তথ্য ডেটাবেসে তোলে। "তথ্য:" অংশের বদল লাইভে দেখাতে অ্যাডমিনের "সাইট রিফ্রেশ" চাপুন। কোডের লেখা বদলালে লাইভে নিতে নতুন ডিপ্লয় লাগে।

## ছবি যোগ করা

ছবি সঠিক নামে `public/images/` ফোল্ডারে রাখলেই আপনা-আপনি দেখায়, ডেটা ফাইলে কিছু লিখতে হয় না (`src/lib/images.ts` বিল্ডের সময় ফাইল খুঁজে নেয়):

- হোমপেজের হিরো আর উপজেলা পরিচিতির ফ্রেম: `public/images/hero.jpg` (প্রস্থ ১৬০০–২০০০px)
- গ্রাম: `public/images/villages/<slug>/cover.jpg` (কভার), `1.jpg`, `2.jpg` … (গ্যালারি)
- দর্শনীয় স্থান: `public/images/places/<slug>/cover.jpg`, `1.jpg` …
- শিক্ষা প্রতিষ্ঠান: `public/images/schools/<slug>/cover.jpg`, `1.jpg` … (অ্যাডমিন থেকে আপলোড করাই সহজ)
- বিশিষ্ট ব্যক্তি: `public/images/people/<slug>.jpg`। ছবি যেমন আছে তেমনই দেখায়: পোর্ট্রেট, গোল করে বা কেটে নয়, আর আসল মাপের চেয়ে বড় করেও নয় (হোমপেজে সর্বোচ্চ ৩৬০px উঁচু, তালিকায় ৮০px চওড়া; বড় ছবি শুধু ছোট হয়)। অ্যাডমিন থেকে আপলোড করলেও ছবি কাটা হয় না।
- খবর: `public/images/news/<slug>.jpg`; উৎসব: `public/images/events/<slug>.jpg`
- ফেসবুক শেয়ার প্রিভিউ: `src/app/opengraph-image.jpg` (১২০০×৬৩০)

বিস্তারিত নিয়ম ও মাপ [public/images/README.md](public/images/README.md) ফাইলে। ছবি ১৬০০px চওড়ার বেশি না রাখলে সাইট দ্রুত লোড হবে; Next.js নিজে ছোট সাইজ বানিয়ে নেয়। ছবি না থাকলে আঁকা প্লেসহোল্ডার দেখায়, কিছু ভাঙে না।

ফোল্ডারের ৩৮টা ছবি উইকিমিডিয়া কমন্স থেকে নেওয়া: হরিপুর বড়বাড়ি, গোকর্ণ নবাব বাড়ি, পাগল শংকর জিউ মন্দির, জেঠাগ্রাম, নাসিরনগর সদর, ফান্দাউক, নবাব সৈয়দ শামসুল হুদা, নৌকা বাইচ, আর শিক্ষা প্রতিষ্ঠানের মধ্যে নাসিরনগর সরকারি কলেজ, আশুতোষ পাইলট উচ্চ বিদ্যালয়, জেঠাগ্রাম সরকারি প্রাথমিক বিদ্যালয় ও আইএলএসটি নাসিরনগর। সবই মুক্ত লাইসেন্সের (CC BY-SA 4.0, CC0 বা পাবলিক ডোমেইন)। প্রতিটার লেখক, লাইসেন্স আর উৎস আছে `content/image-credits.json`-এ। সেখান থেকেই ছবির নিচের কৃতজ্ঞতা, গ্যালারির লাইটবক্সের লেখা আর "আমাদের সম্পর্কে" পেজের "ছবির কৃতজ্ঞতা" তালিকা তৈরি হয়। অন্যের তোলা ছবি নতুন যোগ করলে এই ফাইলেও লিখুন। গুগল সার্চ বা ফেসবুকের ছবি সাধারণত কপিরাইট করা, তাই অনুমতি ছাড়া নেওয়া হয়নি।

## শিক্ষা প্রতিষ্ঠান (/schools)

উপজেলার স্কুল, কলেজ ও মাদ্রাসার তালিকা: `content/schools.json` (ডেটাবেসে `schools`)। প্রতিটা প্রতিষ্ঠানের নিজস্ব পেজ `/schools/<slug>`-এ নাম, ছবি, প্রতিষ্ঠাকাল, ধরন ও স্তর, EIIN, প্রতিষ্ঠাতা, প্রতিষ্ঠান প্রধান, শিক্ষার্থী-শিক্ষক সংখ্যা, যোগাযোগ, ইতিহাস, গ্যালারি, মানচিত্র আর তথ্যসূত্র দেখায় (যা দেওয়া আছে শুধু সেগুলো)।

- **তালিকা পেজ:** ধরন অনুযায়ী ভাগ করা (কলেজ, স্কুল অ্যান্ড কলেজ, উচ্চ বিদ্যালয়, নিম্ন মাধ্যমিক, মাদ্রাসা, কারিগরি, প্রাথমিক)। নাম, গ্রাম বা EIIN দিয়ে খোঁজা যায়, ইউনিয়ন ও ধরন বাছাই করা যায়।
- **গ্রাম ও ইউনিয়নের পেজ:** প্রতিষ্ঠানে গ্রাম বাছাই করা থাকলে সেই গ্রামের পেজের "শিক্ষা প্রতিষ্ঠান" অংশে দেখায়; ইউনিয়নের পেজে ওই ইউনিয়নের সবগুলো।
- **অ্যাডমিন:** বাঁয়ের "শিক্ষা প্রতিষ্ঠান" মেনু থেকে যোগ, এডিট, ছবি আপলোড ও মোছা। প্রতিষ্ঠাকাল বা EIIN বাংলা অঙ্কে লিখলেও চলে।
- গ্রামের ফর্মের "অন্যান্য প্রতিষ্ঠান" অংশে এখন শুধু মসজিদ, মন্দির, স্বাস্থ্যকেন্দ্রের মতো প্রতিষ্ঠান থাকে; আগের স্কুল-কলেজ-মাদ্রাসাগুলো শিক্ষা প্রতিষ্ঠানের তালিকায় সরানো হয়েছে।
- কারও ব্যক্তিগত মোবাইল নম্বর নয়, শুধু প্রতিষ্ঠানের নিজস্ব যোগাযোগ দিন। প্রধান শিক্ষক বা অধ্যক্ষ বদলালে নামও হালনাগাদ করুন।

## দর্শনীয় স্থান, ব্যক্তি, খবর, উৎসব

অ্যাডমিন প্যানেলের সংশ্লিষ্ট মেনু থেকে যোগ/এডিট করুন (ডেটাবেসে `places`, `people`, `news`, `events`; ফাইল-মোডে `content/places.json`, `people.json`, `news.json`, `events.json`)। স্থানে "হোমপেজে দেখান" টিক দিলে হোমপেজে আসে। জীবিত ব্যক্তির তথ্য ও ছবি যোগ করার আগে অনুমতি নিন।

## "তথ্য দিন" ফর্ম

ফর্ম জমা দিলে `src/actions/contribute.ts` সার্ভার অ্যাকশন চলে। তথ্য ডেটাবেসের `submissions` টেবিলে জমা হয় (ডেটাবেস না থাকলে `submissions/` ফোল্ডারে JSON ফাইল হিসেবে), আর অ্যাডমিনের "জমা পড়া তথ্য" পেজে দেখা যায়। জমা রাখা না গেলে ফর্ম ব্যবহারকারীকে পরে আবার চেষ্টা করতে বলে, আর পুরো তথ্য সার্ভারের লগে থাকে।

## ডিপ্লয় (Vercel)

```bash
npm i -g vercel
vercel            # প্রিভিউ
vercel --prod     # প্রোডাকশন
```

Vercel প্রজেক্টের Settings → Environment Variables-এ দিন (Production ও Preview দুটোতেই):

- `DATABASE_URL`: Neon-এর connection string। এটা ছাড়া লাইভ সাইটে অ্যাডমিন থেকে এডিট বা ফর্মে তথ্য জমা করা যাবে না।
- `ADMIN_PASSWORD`: অ্যাডমিন প্যানেলের পাসওয়ার্ড।
- `NEXT_PUBLIC_SITE_URL=https://আপনার-ডোমেইন`: sitemap ও OG ট্যাগে লাগে।

বিল্ডের সময়ও ডেটাবেস থেকে পেজ তৈরি হয়, তাই `DATABASE_URL` বিল্ডেও পাওয়া যেতে হবে (Vercel-এ আপনা-আপনি পায়)। Vercel-এ একবারে ৪.৫ MB-এর বেশি পাঠানো যায় না। ছবি ব্রাউজারেই ছোট হয়, তবু অনেক ছবি একসাথে দিলে সেভ ব্যর্থ হতে পারে; তখন কয়েকটি করে আপলোড করুন। `.env.example` দেখুন।

## তথ্যসূত্র ও সতর্কতা

- **নাসিরনগর উপজেলা পোর্টাল** (nasirnagar.brahmanbaria.gov.bd, অক্টোবর ২০২৬-এ সংগৃহীত): ইউনিয়নের চেয়ারম্যানের নাম ও গ্রামের তালিকা ("এক নজরে নাসিরনগর"), উপজেলার পটভূমি, ভৌগোলিক পরিচিতি, নদ-নদী, খেলাধুলা ও সংস্কৃতি, প্রখ্যাত ব্যক্তিত্ব, হরিপুর বড়বাড়ির বিবরণ, হাসপাতাল, যোগাযোগ, পোস্টকোড (৩৪৪০) ও জাতীয় জরুরি নম্বর (`src/data/upazila.ts`, `unions.ts`, `people.ts`, `places.ts`, `emergency.ts`, `transport.ts`)।
- **বাংলা ও ইংরেজি উইকিপিডিয়া**: ইউনিয়নের আয়তন, ২০১১ আদমশুমারির জনসংখ্যা, মৌজা, স্থানাঙ্ক, হাট-বাজার ও প্রতিষ্ঠান। পোর্টালের জনসংখ্যা পুরনো শুমারির (সব ইউনিয়ন মিলে প্রায় ২.৫৬ লাখ), তাই সাইটে ২০১১-এর সংখ্যা রাখা হয়েছে।
- **বিবিএস ২০২২**: উপজেলার আয়তন, জনসংখ্যা ও সাক্ষরতার হার।
- পোর্টাল ও উইকিপিডিয়ার গ্রামের তালিকা মিলিয়ে নেওয়া হয়েছে; পোর্টালের অতিরিক্ত নামগুলো প্রতিটি ইউনিয়ন ফাইলের শেষে মন্তব্যসহ আছে। শ্যামপুর গ্রাম উইকিপিডিয়ায় পূর্বভাগে, পোর্টালে হরিপুরে; সাইটে পূর্বভাগে রাখা হয়েছে।
- চেয়ারম্যানের নাম পোর্টালের জানুয়ারি ২০২২-এর হালনাগাদ অনুযায়ী; বদলালে `unions.ts`-এ `chairman` বদলান। স্থানীয় ফোন নম্বর, হাটবার, ভাড়া ও উৎসবের তারিখ যাচাই করে বসাতে হবে। মানচিত্রে গ্রামের অবস্থান এখন ইউনিয়ন কেন্দ্রের আনুমানিক স্থানাঙ্ক; গ্রামের `lat`/`lng` দিলে সঠিক হবে।
