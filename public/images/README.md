# ছবি রাখার নিয়ম

ছবি এই ফোল্ডারে সঠিক নামে রাখলেই সাইটে আপনা-আপনি দেখাবে; ডেটা ফাইলে কিছু লিখতে হয় না।
(ডেটা ফাইলে `cover` দিলে সেটিই অগ্রাধিকার পায়।)

| কী | কোথায় রাখবেন | মাপ |
| --- | --- | --- |
| হোমপেজ ব্যানার | `hero.jpg` | ১৯২০×৬৪০ (৩:১), landscape |
| গ্রামের কভার | `villages/<slug>/cover.jpg` | ১৬০০×১২০০ (৪:৩) |
| গ্রামের গ্যালারি | `villages/<slug>/1.jpg`, `2.jpg`, `3.jpg` … | ১৬০০px চওড়া |
| দর্শনীয় স্থানের কভার | `places/<slug>/cover.jpg` | ১৬০০×১২০০ (৪:৩) |
| দর্শনীয় স্থানের গ্যালারি | `places/<slug>/1.jpg`, `2.jpg` … | ১৬০০px চওড়া |
| বিশিষ্ট ব্যক্তির ছবি | `people/<slug>.jpg` | যেমন আছে তেমন, পোর্ট্রেট (চওড়া ৮০০px-এর বেশি না রাখলেই হয়) |
| খবরের ছবি | `news/<slug>.jpg` | ১৬০০×১২০০ (৪:৩) |
| উৎসবের ছবি | `events/<slug>.jpg` | ১৬০০×১২০০ (৪:৩) |

- `<slug>` মানে ডেটা ফাইলে দেওয়া slug, যা URL-এও থাকে। যেমন `/villages/haripur` → `villages/haripur/cover.jpg`, `/places/haripur-barabari` → `places/haripur-barabari/cover.jpg`, `/people` পেজের নবাব সৈয়দ শামসুল হুদা → `people/syed-shamsul-huda.jpg`।
- `.jpg`, `.jpeg`, `.png`, `.webp` সবই চলে; ছবির নাম ইংরেজি ছোট হাতের অক্ষরে রাখুন।
- ফাইল ৫০০ KB-এর মধ্যে রাখলে ভালো; Next.js নিজে ছোট সাইজ বানিয়ে পাঠায়।
- নিজের তোলা বা অনুমতি নেওয়া ছবি ব্যবহার করুন; মানুষের ছবি দেওয়ার আগে তাঁর অনুমতি নিন।
- গুগল সার্চ বা ফেসবুকের ছবি সাধারণত কপিরাইট করা, অনুমতি ছাড়া দেবেন না। উইকিমিডিয়া কমন্সের মতো জায়গার মুক্ত লাইসেন্সের (CC BY, CC BY-SA, CC0, পাবলিক ডোমেইন) ছবি দেওয়া যায়, তবে লেখকের নাম আর লাইসেন্স দেখাতে হয়: `content/image-credits.json`-এ ছবির পথ ধরে `title`, `author`, `license`, `licenseUrl`, `source` (দরকার হলে `note`) লিখে দিন। তাহলে ছবির নিচে আর "আমাদের সম্পর্কে" পেজের "ছবির কৃতজ্ঞতা" তালিকায় নিজে থেকেই দেখাবে।
- নতুন ছবি রাখার পর `npm run dev` চালু থাকলে পেজটা রিলোড করুন; প্রোডাকশনে নতুন করে বিল্ড লাগে।
